# Book summarization agent

In this example we will create a book summarization agent that utilizes Gogi as a platform for AI development.
The user will upload a book in a PDF format. A user specified pipeline will be triggered in the background to extract the chapters from the book.
Once the pipeline is finished, the user will be able to ask for chapter summarization. Overall, this chapter will show you how to use collectively
the following services:

- Indexes
- Prompts
- Models
- Workflows
